📱 Panduan Akses HP Android & Hosting GitHub

1. Cara Install Jadi Aplikasi di HP Android (PWA WebAPK)

Aplikasi ini sudah dilengkapi manifest.json & sw.js offline ready:

  1. Buka website ini lewat browser Google Chrome di HP Android kamu.
  2. Klik tombol titik tiga (⋮) di pojok kanan atas Chrome, lalu pilih "Tambahkan ke Layar Utama" atau "Install Aplikasi".
  3. Ikon KAS-TKJ1 akan langsung muncul di menu aplikasi HP dan jalan full-screen tanpa address bar browser!

2. Cara Deploy Gratis ke GitHub Pages (Online 24 Jam)

Agar bisa diakses oleh guru dan teman sekelas tanpa tergantung laptop lokal:

cd /home/nza/Projects/kas-tkj
git init
git add .
git commit -m "feat: Sistem Kas XII TKJ 1 v1.0"
git remote add origin https://github.com/USERNAME/kas-tkj1.git
git branch -M main
git push -u origin main

Setelah dipush, buka repo di GitHub ➔ Settings ➔ Pages ➔ Branch: main / root ➔ Klik Save. Website langsung online!
